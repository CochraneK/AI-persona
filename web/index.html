这是什么

What This Is

这是一个纯 Python 标准库、零外部依赖的生成引擎。它的本体（ontology）描述的不是一个病人， 而是一个完整的人——一生被拆进 18 个语义命名空间，从「生命历程」到「此刻的状态」， 每个命名空间只负责回答一个唯一的问题。诊断（抑郁症、强迫症……）只是其中一个命名空间， 只决定症状学的外壳；真正塑造人物心理内核的，是 wound → desire → need 这条叙事因果链。 所以池子里既有健康对照，也有患者——精神病学 AI 评估是它的应用之一，不是它的全部。
