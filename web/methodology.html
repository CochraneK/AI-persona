00核心是什么Core Thesis

一句话：先定义「人是什么」，再实例化「一个具体的人」。 Human Ontology v2 是唯一的语义权威（18 个语义域 / 205 概念 / 类型化关系 / 证据来源纪律），Persona Engine 负责把语义实例化成一个具体的人——最终组装成可直接喂 LLM 的 System Prompt。 精神科诊断不再是「人的根」，而是 18 域中一个可选的健康模块：同一个人，带不带诊断，都是完整的档案。

02借鉴了什么Provenance of Ideas
借鉴对象本项目怎么用
BFO 上层本体 (Basic Formal Ontology)六种本体类型 entity / quality-disposition / role / relation / process-event / state 显式分治——role 不是 event（角色转换才是 event），state 不是 trait，连续值与离散分类不混进同一棵树
语义网 (RDF / OWL / SHACL) + Gruber competency questions「一个概念一个 canonical home」= 语义层的参照完整性 + 单一事实源；投影成 RDF/OWL/SHACL 做漂移检查；184 条 competency questions 作为 Tier A 机器验收
McKinsey MECE改造成局部 MECE：只有回答同一问题、同一抽象层级的同级分类才要求互斥穷尽；连续 / 多值 / 关系 / 时间性事实显式声明语义，不假装 MECE
大五人格 (McCrae & Costa, FFM)明确降格：personality_psychology.temperament_traits 下的一个特质模型，不是本体 MECE 分区；只做措辞微调，不覆盖人设型（诊断条件化范围仅作 legacy 复现）
Will Storr 《The Science of Storytelling》Wound→Lie→Desire→Need 叙事因果链：formative_wound / dysfunctional_beliefs / compensatory_desire / storr_need 四字段，让人物有「所以然」而不只是「是什么」
Lajos Egri 三维角色论 + K.M. Weiland 《Creating Character Arcs》core_desire / core_fear（静态维度）+ 三种角色弧线（正/负/平坦），按临床轨迹推理映射 37 诊断：27 正弧 / 4 负弧 / 6 平坦弧
Beck 认知三角 + Bracha 5F 应激模型dysfunctional_beliefs（自己/世界/未来）+ stress_pattern（Fight/Flight/Freeze/Fawn/Self-harm，primary + secondary）
ICD-11 Ch.06 + DSM-5-TR + Holmes-Rahe LCU + ACEs + Erikson诊断知识库（278→37 生成范围，含共病）· 6 域×4 阶段 143 事件模板矩阵（LCU 应激评分）· 触发器系统 · Erikson 发展阶段字段
普查 / 流行病学分层抽样性别比按诊断加权（厌食→90% 女、ASD→80% 男）、6 年龄带、7 级教育、52 国按世界人口加权——人口学来自真实分布，不是抛硬币
W3C PROV 风格 provenance五种认知来源 observed / measured / inferred / generated / input_constraint 互不冒充；推断与生成值必须携带 provenance + confidence + 时间类；unknown ≠ absent
W3C CR→REC / 软件工程发布纪律本体变更受治理（先查 registry、定 kind、验迁移、过 gate）；release gate 全绿才能 canonical 转正；验证分级声明，机器绿 ≠ 人类验证，AI 共识 ≠ 真值
03为什么这么做：六个决策Design Decisions
1
诊断当根 → 刻板印象机器Diagnosis-as-root problem
初版以诊断为采样根：OCEAN、原型、事件全按诊断条件化，等于让诊断悄悄决定人格与人生史。→ Person-first：诊断降为可选健康模块，防火墙是可测试不变式（同 seed 换诊断，非健康字段逐字节一致），不是口号。
2
10²⁹ 空间幻觉 → 硬网格From nominal combos to enumerable grid
名义组合数巨大，但深层字段模板池极小（每诊断仅 1 条 wound / 1 条 need），内核严重同质且不可覆盖验证。→ Archetype Grid：有限显式声明，「有多少种不同的人」第一次变得可回答（45 型 / 720 身份），实测深层去重率提升 3.5~10×。
3
全局 MECE 是陷阱 → 局部 MECE + 六型分离The global-MECE trap
人的事实含连续值、多值、关系、时间性，强行压进一棵互斥树必然产生虚假二分。→ 域是命名空间不是分区：同级分类才 MECE；跨域事实用类型化关系连接而不是复制字面量。
4
OCEAN 抹平人设型 → 型优先OCEAN flattening
adjust_*_by_ocean() 在极端 OCEAN 下整体替换 wound/desire/need 文本，人设型被抹平。→ 型专属模板优先，OCEAN 只做措辞微调；生成器刻意不传 ocean 给这些函数，并写入改动守则。
5
多项目共享 → canonical registry + 契约Cross-project interop
AI-Persona / P003 / AI-Ques 需要同一套语义层，否则各建一套、语义漂移。→ 一个概念一个 home + 消费方契约 + 186 个字段级迁移映射：旧 API 仍可运行、旧数据集仍可复现，迁移不是重写。
6
验证诚实 → 分级声明Honest validation tiers
机器门绿 ≠ 人类验证，多 AI 共识 ≠ 真值（可能一起错）。→ Tier A/B1/B2/C 分级：当前仅 A 达成、B1 就绪、C 未达成，文档明确禁止把绿门描述成科学有效性；B1 专设「一致但错」指标拦截集体误判。
04巧妙的技术细节Clever Details
①正交单一语义家
一个概念只定义一次，别处一律 typed reference / projection。「UI 允许重复，本体不允许」——把数据库 3NF 的思想用到语义层。
②局部 MECE
约束只加在「同问同层」的同级分类上；OCEAN 五维虽是正交因子，在 v2 中被显式降格为「特质模型，不是 MECE 分区」——MECE 本身也被当成需要治理的声明。
③六个「≠」
role≠event（角色转换是 event）、state≠trait、出生地≠文化≠国籍、诊断≠症状≠损害≠身份、关系观察≠全局特质、结构约束≠人格缺陷——每一条都是曾真实混淆过的案例。
④可测试的语义防火墙
health_only 防火墙落在契约测试上：同 seed 换诊断，非健康人格与人生史必须逐字节一致。诊断影响被限定在 health/current-state 载荷内。
⑤第 4 条独立 RNG 流
本体原生 5 域采样器从 sha1(diagnosis_key, seed) 派生独立种子——新增 59 个概念，既有 34 字段逐字节不变；与 PYTHONHASHSEED 无关。非侵入式演化。
⑥硬网格替代软概率
Archetype 是有限显式声明而非概率软约束：空间可枚举、可覆盖、可出报告（python core/archetypes.py），「覆盖了多少种人」成为可回答的问题。
⑦普查校准分层采样
性别/年龄/教育全部锚定真实分布（厌食 90% 女、ASD 80% 男、6 年龄带、7 级教育、52 国人口加权），消灭抛硬币式的人口学。
⑧Provenance 纪律
observed/measured/inferred/generated/input_constraint 五种认知来源互不冒充；unknown ≠ absent；推断与生成值强制携带 provenance + confidence + 时间类。
⑨类型化关系 + 谓词约束
typed EntityRef 端点，每个谓词约束目标类型（works_for→organization、born_in→place、uses_language→language）——参照完整性进语义层。
⑩元数据完整性
每个域值必须有匹配字段元数据，孤儿值 / 缺失元数据在 validate() 被拒绝——数据质量靠 schema 强制，不靠约定。
⑪3 段 id 地址空间
全量池 P-000001~005000 / 展示池 P-000001~000070（池内局部）/ 实时卡 P-100000~199999（sha1(diag#seed) 派生）——互不重叠、全部可寻址、实时卡可复现。
⑫纯标准库 · 零依赖
整个引擎 + 全部 web 页面只用 Python/JS 标准库：零外部请求、双击即开、任意机器可复现——工程约束本身成为可移植性保证。
