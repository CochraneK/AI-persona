# Human Ontology Claims Discipline

## Claims currently supported

You may accurately say:

- Human Ontology v2.0.0-rc2 has a reviewed runtime contract with 18 semantic namespaces, 31 reviewed first-class concepts, 22 typed relation families and a 205-concept exhaustive catalog.
- The reviewed runtime contract currently passes **184/184 declared machine competency questions**.
- The semantic-web projection is reproducible from canonical JSON and matches **4/4 committed RDF/OWL/SHACL projection files**.
- The evaluation layer includes 24 adversarial semantic-boundary cases, 30 diversity stress cases, a deterministic Multi-AI Tier-B1 benchmark, provider adapters and an agreement/accuracy analyzer.
- The Multi-AI analyzer explicitly detects **agreement-but-wrong**, so model consensus is not treated as truth.
- **56 provisional relation leaves** have accepted semantic homes but still require predicate/runtime review before being treated as stable APIs.

## Claims supported only after Tier B1 passes

You may then say:

> Under the dated benchmark protocol, the reviewed Human Ontology semantic boundaries were robust across the tested AI model/provider set.

You still may **not** translate that into “independent human experts agree”.

## Claims not yet supported

Do not yet say:

- “Human Ontology is scientifically validated” without qualification;
- “Human Ontology is a complete ontology of human beings”;
- “The 18 namespaces are globally MECE”;
- “The ontology is cross-culturally universal”;
- “The ontology is clinically validated”;
- “Independent experts agree with the mappings”;
- “The ontology improves downstream AI systems”;
- “All 205 concepts are stable runtime APIs”;
- “SHACL / OWL reasoner validation has passed” until actually executed.

## Evidence still required

Current priority:
- a real Tier-B1 run using >= 3 different AI model/provider families;
- archived exact model IDs, hashes and outputs;
- systematic external term-level mapping decisions;
- P003 and AI-Ques before/after evaluation;
- actual pySHACL execution and fuller reasoner review;
- FAIR assessment after publication.

Optional stronger evidence:
- independent human/domain-expert review;
- external research-team reproduction.

## Reporting preference

Report an **evidence profile**, not one global “scientific score”.
