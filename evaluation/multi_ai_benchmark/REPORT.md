# Multi-AI Benchmark Report

**Status:** not_run  
**Evidence tier:** Tier B1 candidate  
**Current result:** No external model outputs are committed.

The benchmark infrastructure is ready, but a scientific claim must wait until dated outputs from multiple genuinely different model/provider families are collected and analyzed.

## Required report fields after a run

- exact model IDs / provider / run date;
- item and response counts;
- domain accuracy by model;
- forbidden-inference false-positive rate by model;
- pairwise agreement by dimension;
- Fleiss' kappa where balanced;
- consensus accuracy;
- agreement-but-wrong cases;
- failures by adversarial theme;
- prompt hash / benchmark case hash;
- known API errors / refusals / missing outputs.

Do not replace these with one aggregate “AI score”.
